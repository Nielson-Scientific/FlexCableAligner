# CSVCreator

CSVCreator is a graphical tool for generating CSV files required by **FlexCableAligner**. It loads DXF drawings, lets the user define an origin and two landmarks, and then interactively creates point pairs that are exported as a CSV.

## Quick start
```bash
cd CSVCreator
python main.py
```
The GUI will open, allowing you to load a DXF file and begin creating points.

For detailed usage instructions see the [USAGE guide](docs/CSVCreator/USAGE.md).
